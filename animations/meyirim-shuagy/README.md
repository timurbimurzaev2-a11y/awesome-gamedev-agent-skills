# Мейірім шуағы (Ray of Kindness)

Сөзсіз қысқа мультфильм (1 мин 22 сек, 1280×720, 24 fps). Кейіпкерлер сөйлемейді — бәрі тек
мимика мен қимыл арқылы баяндалады. Фонда жұмсақ аспаптық музыка ғана бар.

**Видео:** [`meyirim-shuagy.mp4`](meyirim-shuagy.mp4)

## Сюжет

| Уақыт | Не болады |
|-------|-----------|
| 0:00–0:07 | Саябақ. Орындықта бала көк шарын ұстап, күліп отыр. Күн де күліп тұр. |
| 0:07–0:18 | Жел соғып, шар ұшып кетеді. Бала таң қалады, сосын жылайды. Күнді бұлт жауып, аспан күңгірттенеді. |
| 0:18–0:28 | Қызыл шары бар қыз көңілді келе жатып, жылап отырған баланы байқайды. |
| 0:28–0:34 | Қыздың бетінде аяушылық. Өз шарына, сосын балаға қарайды — ойланады да, жымиып шешім қабылдайды. |
| 0:34–0:46 | Қыз шарын балаға сыйлайды. Баланың көз жасы тыйылып, қуанып күледі. Күн бұлттың артынан шығады. |
| 0:46–0:56 | Екеуі секіріп қуанады, жүректер ұшады, гүлдер ашылады. |
| 0:56–1:05 | Мұңды мысық келеді. Бала оны еркелетіп сипайды — енді мейірімді бала өзі жақсылық жасайды. Мысық бақытты. |
| 1:05–1:16 | Кемпірқосақ, құстар, үшеуі де бақытты қол бұлғайды. |
| 1:16–1:22 | «Мейірімділік — бақыттың кілті». Соңы. |

## Қайта жасау

Бәрі кодпен салынған (Python + Pillow + NumPy, ffmpeg):

```bash
python3 render.py meyirim-shuagy.mp4          # толық видео
python3 render.py --still 15 33 45             # жеке кадрлар (секунд бойынша)
```
